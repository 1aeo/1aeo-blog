# Shared 1AEO Blog Chart Helpers

Reusable styling, font normalization, and display-precision modules used across 1AEO measurement charts. Neither module contains relay data, private identities, or deployment logic.

- `blog_chart_style.py` — Shared color palette, desktop/mobile pixel-to-point typography scaling, and UTF-8 SVG font-stack normalization (`Arial, Helvetica, sans-serif`).
- `blog_display_numbers.py` — Whole-number display rounding, bounded percentage formatting, and ratio/signed-change helpers.
