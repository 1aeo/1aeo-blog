Version scope: Tor 0.4.9.14 with our custom metrics patch. Tor 0.4.9.15, released October 28, adds directory-request DoS controls, including per-circuit BEGIN_DIR rate limiting and a hidden-service directory (HSDir) request limit. The measurements below describe 0.4.9.14, not the effect of those new controls.

Relay letters are stable anonymized labels; repeated letters identify the same relay. We compare 89 observed periods on 64 relays. A directory stream carries requests inside a Tor circuit; BEGIN_DIR asks the relay to open one.

Closed while waiting for an HTTP request was the majority of classified streams in 51 periods. This occurred on 46 relays; those periods averaged about 2½ h. In Relay T’s approximately three-hour observation, 57,501,531 closures (98.2%) received this classification.

HSDir GET requests were the majority of classified streams in 38 periods. This occurred on 30 relays; those periods averaged about 3¼ h. Relay O recorded 14,526,740 HSDir GET requests (99.8%) over about 2½ h.

Majority classifications differed across observations on 12 relays. Their 26 observations averaged about 2¼ h. Relay N had 94.5% classified “Closed while waiting for an HTTP request” in an earlier observation and 99.7% HSDir GET requests in a later one.

Methods

A directory stream is carried inside a Tor circuit; BEGIN_DIR requests stream setup. The traffic-path diagram provides protocol context, and our Tor Project GitLab proposal describes the added counters.

These are saved cumulative counter increases from Tor 0.4.9.14 with custom metrics. A majority means strictly more than half of an observation’s classified directory streams. The 38 HSDir GET request-majority periods and 51 “Closed while waiting for an HTTP request” majority periods cover all 89 observations. Twelve relays appear in both groups in separate observations; the third finding describes that overlap, not a third category.

Observed periods are not necessarily complete floods. Cumulative counts are complete within their recorded spans; 44 periods have gaps in minute-level rates. BEGIN_DIR peaks are the highest observed interval-average cell rates, not instantaneous maxima, and gaps may hide higher rates. Public starts and durations are independently rounded to 15-minute blocks; the displayed end is their sum. Counts, shares and mean observation durations use the original private intervals.

“Closed while waiting for an HTTP request” is our custom metric label for directory streams that close in Tor’s HTTP-request-wait state, with an empty input buffer and no earlier request classification. It does not establish the closure cause or whether bytes arrived earlier. “Unparsed directory streams” includes invalid or unrecognized input and remaining unclassified streams counted at closure, such as partial buffered requests. “Other directory routes” combines “Server / extra-info descriptor GET requests”, “Other GET requests” and “Other POST requests”. Classifications do not establish client delivery or resource cost.
