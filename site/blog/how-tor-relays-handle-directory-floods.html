Methods

HSDir GET requests retrieve onion-service descriptors; HSDir POST requests submit them for storage. Saved counter increases cover measured periods, not necessarily entire attacks. HSDir GET and HSDir POST handling each cover the same 25 periods on 20 relays; directory-stream classification/response-byte comparisons cover 29. Missing handling entries are not zero. HSDir GET and HSDir POST handling shares each use their own request total. Byte shares use all nine internal response-byte categories. Server / extra-info descriptor GET requests combine both descriptor routes; “Other GET requests” and “Other POST requests” describe remaining routes, not peer intent. Pattern totals sum the included periods; request totals include all handling results. Per-period averages divide totals by the period count. Combined relay-hours sum measured durations across relays, counting simultaneous observations separately. Request averages are rounded to whole requests; byte amounts use decimal gigabytes. Average durations cover whole measured spans grouped by their overall handling or response-byte mix, with each period weighted equally. They do not measure continuous time in a handling category. Relays can appear in several groups. Means are calculated before rounding.

Handling result labels come from our custom metrics, not HTTP status codes. “Response queued” does not establish client delivery. “Descriptor stored” means accepted into storage, not a completed client exchange. “Descriptor not newer” can include unchanged descriptors. Closing-circuit and client-channel rejections remain separate. Internal response bytes follow the directory-stream classification and include error-response bytes. They count normal linked-stream handoffs; some forced close-time moves are outside this hook. Matching a directory-stream classification’s aggregate count and bytes does not link individual requests to responses or establish per-request wire costs. Whole-relay network accounting is a separate layer.

Observed group peaks are the highest supported native-interval rates within each majority-pattern group, attributed to one relay rather than summed. The quoted peaks use 60-second samples and are not instantaneous maxima; sampling gaps may hide higher rates. HSDir GET/POST rate panels show whole-period means; paired type panels show cumulative counts and GB. Calculations use original measured durations. Public UTC starts and durations are rounded to 15-minute blocks; displayed ends follow from those rounded values. Sampling gaps are not interpolated, and observed zeros remain zero. “Closed while waiting for an HTTP request” is our custom metric label for directory streams that close in Tor’s HTTP-request-wait state, with an empty input buffer and no earlier request classification. It is not a timeout cause. Buffered partial input can instead be unparsed. These unknown stream classifications remain in the counts.
